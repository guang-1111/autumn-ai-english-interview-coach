# 秋招AI英语面试教练

把简历、目标岗位和复习资料交给 AI，生成适合自己的英文语料，开展会根据回答继续追问的模拟面试，并在结束后获得逐题反馈。

这是一份可上传或粘贴到 AI 对话中的 skill，适用于秋招、实习及社会招聘的英语面试准备，支持不同专业与岗位。

## 目的

帮助求职者把自己的经历和专业知识整理成能说出口的英语，并通过问答检查表达、知识理解和岗位匹配情况。

AI 会主动引导用户选择功能、提供材料和确定训练时长。用户可以先准备背诵资料，也可以直接开始模拟，训练中发现的薄弱点会用于后续复习。

## 功能

| 功能 | 可以得到什么 |
|---|---|
| 个性化复习语料 | 自我介绍、经历讲述、重点词汇与搭配、专业知识英文短答及可能追问 |
| 实时模拟面试 | 一次一个问题，根据回答追问具体行动、判断依据、过程、结果或方案取舍 |
| 结合岗位描述准备 | 根据简历与 JD 调整提问重点，同时考察岗位需要的专业知识和情境判断 |
| 自选面试时长 | 5、10、15、20、25 或 30 分钟 |
| 逐题反馈与复习建议 | 每题回答表现、具体依据、改进建议，重点问题的英文示范回答和后续练习方向 |

追问会在信息足够、短板已经明确或需要覆盖其他能力时结束，随后进入下一题。

支持两种训练方式。教练模式会在每个主问题及追问结束后纠正、改写并安排复述。严格模拟会连续进行问答，在面试结束后统一反馈。

## 使用方法

### 1. 上传 skill 并发送启动提示

下载本目录中的 skill，打开一个新的 AI 对话，上传文件或粘贴全文。随后发送下面这句话，明确告诉 AI 开始带领训练。

[下载《秋招AI英语面试教练》](./秋招AI英语面试教练.md)

> 请按照附件 skill 担任我的英语面试教练。先询问我想使用哪个功能，再引导我提供简历、可选复习素材或岗位描述，材料齐后直接开始。

### 2. 选择需要的功能

AI 会先请你选择生成背诵资料、直接模拟面试，或结合岗位描述定向准备。回复选项，也可以直接描述自己的需求。

### 3. 根据引导提供材料

| 材料 | 用途 |
|---|---|
| 简历或文字版经历 | 了解教育、实习、项目与个人贡献，准备经历稿和简历面试 |
| 目标岗位或方向 | 确定准备重点和提问深度 |
| 岗位描述 JD，可选 | 对照岗位职责和能力要求准备 |
| 英语素材、专业笔记、案例等，可选 | 把自己搜集的资料转化为词汇、知识短答及训练问题 |

只有简历也可以开始。暂时没有简历时，可以用文字介绍经历。材料可以分批发送，发完后告诉 AI 已经发完。分享材料时可先隐去联系方式和客户保密信息。

### 4. 开始准备或面试

选择生成资料后，AI 会按模块整理内容。选择模拟后，AI 会让你从六个时长选项中选择，然后提出第一道问题。

你可以随时说“给我几个关键词”“这段改得更口语”“只练项目经历”“换一个问题”“切换严格模拟”或“结束面试”。

### 5. 查看反馈并继续练习

面试结束后，AI 会自动逐题指出回答情况与改进办法，为最需要改善的 1–2 题提供英文示范，并总结优先练习的三项问题。可以根据反馈补充资料、复述答案，再练一轮。

## 使用示例

以下是虚构的产品经理实习面试示例，用于展示交互方式。

上传 skill 并选择功能 3 后，按 AI 引导提供以下信息。

```text
目标岗位是产品经理实习生，先做 15 分钟严格模拟。

我的经历
在一家电商公司实习，整理客服记录和用户反馈，参与注册流程改版。
我负责把反馈按问题类型分类，提出修改建议，并参与方案讨论。

岗位要求
能分析用户需求，确定需求优先级，与设计和开发协作，跟踪改版效果。

补充资料
我会提供一份用户研究笔记。资料已经发完。
```

AI 根据岗位要求，从相关经历开始提问。

> **AI** Tell me about a time you used user feedback to suggest a product improvement.
>
> **用户** I worked with the team on improving the registration process. We collected user feedback and discussed possible changes.
>
> **AI** What was your own contribution, and how did you decide which issues to prioritise?

当用户讲清个人行动与判断依据后，AI 会根据回答继续深挖，或转向其他岗位能力。也可能提出岗位情境题。

> If users request several improvements but the development team has limited time, how would you decide what to build first?

结束后的反馈会结合实际回答，例如指出“首次回答主要描述团队工作，经追问后才补充个人贡献”，并建议开头直接说明自己整理了什么、采用什么判断标准、提出了什么建议。

如果选择先生成资料，同一份输入也可用于准备 user feedback、prioritise requirements、registration flow 等表达，以及用户需求分析和需求排序的英文短答。

## 使用说明

- 面试时长从第一道正式问题开始，材料收集和结束反馈另计。具备可靠计时能力的 AI 可按时间推进，其他情况会按目标时长估算题量，并注明估算。
- 默认英文提问和作答、中文讲解，可按需要调整。文字训练主要评估内容、结构与表达，发音评估需要可分析的音频。
- 文件阅读、联网核查、语音和计时能力取决于所用 AI。遇到资料无法读取时，可粘贴相关文字。涉及专业知识的精确结论，可结合原始资料核对。
